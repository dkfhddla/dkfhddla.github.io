# 소개

안녕하세요, **Jacob**입니다. 실시간 3D 도구와 제품을 만들며 기술적으로 가능한 것과 사용자가 예측할 수 있는 것 사이의 간격을 줄이는 일에 관심이 많습니다.

## 일하는 기준

### 현상부터 본다

에러 문구보다 사용자가 실제로 마주친 상태를 먼저 확인합니다.

### 경계를 정한다

이번 변화가 책임지는 것과 책임지지 않는 것을 분명히 나눕니다.

### 증거로 끝낸다

구현 완료가 아니라 다시 확인할 수 있는 검증 결과까지 남깁니다.

## 지금의 관심사

- 편집기에서 사용자가 직접 만지는 상호작용과 피드백
- 실시간 상태와 저장 데이터 사이의 책임
- AI와 함께 탐색하고 구현하고 검증하는 반복 가능한 방식

이 블로그는 성공한 구현뿐 아니라 잘못 짚은 원인과 아직 확인하지 못한 부분도 함께 기록합니다.
