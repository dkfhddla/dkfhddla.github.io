**기간:** 2019.01 ~ 2019.04\
**환경:** AWS Sumerian, HTML, JavaScript

모바일 VR 공간에서 상품을 3D로 살펴보고 구매 페이지로 이동하는 쇼핑 프로젝트입니다.

VR 공간과 사용자 이동, 상품 오브젝트의 회전·확대, 씬 전환을 구현했습니다. 상품 페이지와 데이터 입출력을 연결하고 가상 공간 안에서 영상을 재생하는 기능도 개발했습니다.
