**형태:** 졸업 작품\
**역할:** 서버 개발\
**환경:** C++, IOCP, Windows Socket

## 3:3 AOS 게임을 위한 서버

3:3 AOS 장르의 게임을 위해 IOCP 서버를 개발한 졸업 작품입니다. 클라이언트 개발자 1명, 서버 개발자 1명, 디자이너 1명으로 구성된 팀에서 서버 프로그래밍을 담당했습니다.

플레이어 접속과 캐릭터 선택, 게임 안에서 발생하는 캐릭터 이동과 전투 로직을 서버에서 처리했습니다.

## 접속과 작업 스레드 분리

사용자 접속을 기다리는 Accepter 스레드와 클라이언트 패킷을 처리하는 Worker 스레드로 서버를 구성했습니다. 서버 초기화 과정에서 CPU 수를 기준으로 Worker 스레드를 생성했습니다.

## 접속 종료와 패킷 처리

클라이언트 연결이 끊어지면 다른 플레이어에게 종료 사실을 알리고 소켓과 사용자 상태를 정리했습니다.

수신 데이터는 버퍼에 저장한 뒤 정해진 프로토콜과 길이에 맞춰 재조립했습니다. 패킷이 일부만 도착하면 남은 데이터를 보관하고, 이후 수신 데이터와 합쳐 처리하도록 구현했습니다.
