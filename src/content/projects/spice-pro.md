## 어떤 도구인가요?

Spice Pro는 배경과 배우, 애니메이션과 카메라를 조합해 이야기를 3D 장면으로 만드는 **Unreal Engine 5 기반 영상 제작 도구**입니다. 준비된 컷 템플릿에서 시작해 배우와 구도, 동작을 바꾸거나 빈 컷에 직접 장면을 구성할 수 있습니다.

제작의 기본 단위인 컷(Cut)은 영화의 한 샷에 해당합니다. 하나의 컷에 카메라와 배우의 애니메이션을 담고, 스토리보드에서 여러 컷과 씬을 관리합니다. 완성한 컷을 템플릿으로 저장해 다른 장면에도 활용할 수 있습니다.

이 페이지는 당시 사용 가이드와 기획 자료를 바탕으로 Spice Pro의 기능과 제작 과정을 소개합니다. 이후 이어진 제작 도구는 [CineV Studio](/projects/cinevstudio/)에서 볼 수 있습니다.

## 담당 역할과 주요 작업

**런타임 타임라인과 Action 시스템, 캐릭터 커스터마이징 UI 개발**을 담당했습니다. Unreal Engine에서 실행 중인 장면을 편집하는 기능을 구현하고, 캐릭터 데이터와 화면을 연결하는 UI 구조를 개선했습니다.

### 런타임 타임라인과 Action 시스템

- **타임라인 편집:** Unreal Sequence를 실행 중 추가·편집할 수 있는 런타임 타임라인을 구현했습니다.
- **동작 제어:** 애니메이션과 소품(Prop)을 제어하는 Action 시스템을 구현했습니다.

### 캐릭터 커스터마이징과 UI 구조

- **UI·데이터 연동:** 캐릭터 파라미터를 편집 화면에 연결하고, 입력값에 따라 달라지는 동적 UI를 구현했습니다.
- **책임 분리:** ViewModel을 활용해 화면 표시와 기능 코드의 책임을 나누었습니다.
- **기능 구현 조율:** 개발자·기획자·UI 디자이너와 커스터마이징 기능의 클라이언트 전환을 조율했습니다.

### 초기 제작 도구와 협업 환경 구축

2021~2022년에는 제작 도구의 편집 UI와 장면·자산 관리 기능을 구현하고, 개발·아트 팀이 함께 작업할 환경을 정리했습니다.

- **Perforce 작업 환경:** Ubuntu 서버를 구성하고 여러 클라이언트의 연결을 검증했습니다. 외부 접속 문제와 설정 문서 오류에 대응하고, 아트용 스트림을 분리해 협업 환경을 정리했습니다.
- **StoryEditor·Visual Editor:** 씬·컷·대사의 시간 규칙과 삭제·편집 요구사항을 검토했습니다. Scene·Cut·Dialogue용 UMG 위젯에 디자인 가이드를 반영하고, 타임라인 구조 변경과 프레임 오차 대응, 테스트 범위 정리를 수행했습니다.
- **Map Editor:** 오브젝트 배치 UI, Explorer, 기즈모, 환경 제어와 저장·불러오기 기능을 구현했습니다.
- **캐스팅·자산 관리:** 삭제·저장·불러오기 과정의 데이터 불일치를 수정하고, 메타휴먼 갱신과 개발·아트 팀의 작업 절차를 조율했습니다.

## 템플릿에서 시작하는 장면 제작

1. **배경 선택:** 새 씬을 추가하고 장면이 펼쳐질 공간을 고릅니다.
2. **컷 구성:** 제공되는 컷 템플릿을 선택하거나 빈 컷을 만들어 스토리보드에 추가합니다.
3. **배우와 연기 설정:** 캐릭터의 외형과 의상을 구성한 뒤 배역에 맞는 배우를 배치하고 동작·이동 경로·표정을 조정합니다.
4. **카메라 연출:** 추천 앵글과 카메라 모션 클립을 활용하거나 프레임별로 카메라 키를 설정합니다.
5. **저장과 출력:** 프로젝트를 저장해 작업을 이어가고, 컷을 템플릿으로 내보내거나 장면을 렌더링합니다.

### 배경과 컷 템플릿 선택

배경 라이브러리에서 실내·도시·스튜디오 등 필요한 공간을 선택합니다. 이어서 컷 템플릿을 검색하고 여러 컷을 한 번에 추가해 장면의 출발점을 만듭니다. 기본 제공 템플릿과 직접 저장한 템플릿을 구분해 불러올 수 있습니다.

## 캐릭터 커스터마이징

등장인물의 외형을 구성하는 캐릭터 커스터마이징 도구도 제공합니다. 캐릭터를 3D 뷰포트에서 미리 보면서 **헤드·헤어·체형 프리셋**을 선택하고, 체형을 조절하거나 씬·컷의 의상을 교체할 수 있습니다. 이 범위는 2022년 11월 작업 항목에 포함되었으며, 작업 기록에 테스트 완료로 남아 있습니다.

### 프리셋 선택에서 세부 외형 편집으로

기본 캐릭터에서 출발해 머리와 헤어 파츠, 바디를 선택하는 방식입니다. 준비된 외형을 조합한 뒤 체형을 조절해 등장인물의 인상을 구체화합니다.

후속 UI 기획은 이를 Actor·Face·Hair·Body 메뉴로 나누고, 프리셋 선택에서 세부 편집으로 들어가는 흐름으로 정리했습니다. 얼굴의 이목구비·피부톤과 체형의 근육량·비만도 등을 조정하는 화면이 포함되어 있습니다. 아래는 **당시 UI 기획 화면**으로, 세부 항목 전체의 출시 완료를 뜻하지는 않습니다.

### 배우의 기본 외형과 장면별 스타일

기획에서는 배우의 기본 외형과 장면에 따라 달라지는 스타일을 구분했습니다. 배우의 얼굴·체형을 유지하면서 의상과 헤어를 바꿔 같은 인물의 다른 모습을 연출하는 구조입니다.

드레스룸 UI에는 의상의 부위별 소재·패턴·색상을 고르고, 조합한 스타일을 **My Look**으로 저장해 다시 사용하는 흐름이 설계되어 있습니다. 아래 화면은 이 확장 방향을 보여주는 기획 자료입니다.

## 장면·속성·시간을 함께 편집

편집 화면은 **3D 뷰포트, 속성·자산 패널, 타임라인**으로 구성됩니다. 뷰포트에서 배치 결과를 보고, 패널에서 배우와 애니메이션을 선택하며, 타임라인에서 시간에 따른 동작을 확인합니다.

![뷰포트·패널·타임라인으로 구성된 Spice Pro 편집 화면 — 당시 사용 가이드의 영역 설명](/assets/projects/spice-pro/editor-overview.webp)

### 배우 배치와 동작·표정 설정

캐스팅 관리에서 배역 정보를 만들고 배우를 미리 지정합니다. 컷에 배치된 배우를 캐스팅 목록의 다른 배우로 교체해 같은 장면을 다른 등장인물로 구성할 수 있습니다.

모션 에디터에서는 배우에 애니메이션을 적용하고, 화면에 표시되는 이동 경로를 참고해 위치를 조정합니다. 이동·회전·크기 조절 핸들인 **기즈모**를 사용해 장면 안에서 직접 배치합니다. 표정연기 에디터에서는 얼굴 표정과 말하기 동작을 편집합니다.

### 카메라 구도와 움직임 연출

배치된 인물과 오브젝트를 기준으로 추천 카메라 앵글을 확인하고, 줌인·줌아웃 등 자주 사용하는 카메라 모션 클립을 적용할 수 있습니다.

직접 연출할 때는 원하는 프레임으로 이동해 카메라 위치·회전·줌 등의 값을 조정한 뒤 **Set Key**로 기록합니다. 여러 프레임에 저장한 키를 통해 카메라의 움직임을 구성합니다.

![인물의 거리와 각도에 따른 추천 카메라 앵글 목록](/assets/projects/spice-pro/camera-angles.webp)

## 작업 저장과 컷 재사용

영상 프로젝트와 컷 템플릿은 서로 다른 작업 단위를 보존합니다. 프로젝트는 스토리보드 작업을 이어가기 위한 파일이며, 컷 템플릿은 개별 연출을 다시 활용하기 위한 자산입니다.

| 작업 | 사용 방식 |
| --- | --- |
| 프로젝트 저장·불러오기 | 스토리보드의 작업 내용을 저장하고 다시 열어 편집 |
| 컷 템플릿 내보내기 | 카메라와 애니메이션을 포함한 개별 컷을 저장 |
| 내 템플릿 불러오기 | 저장한 컷을 My Template에서 선택해 씬에 추가 |
| 렌더링 | 구성한 장면을 프레임별 이미지로 출력 |

장면 편집과 출력 설명은 당시 Spice Pro 사용 가이드 기준이며, 렌더링 결과는 프레임별 이미지로 저장하는 방식입니다. 캐릭터 커스터마이징은 테스트 완료 기록과 후속 UI 기획을 구분해 소개했습니다.
