**기간:** 2026.05 ~ 2026.07\
**환경:** GitHub Actions, GitHub API, Linear, Slack, 테스트 자동화

## 반복적인 상태 확인을 줄이는 자동화

PR 리뷰, Linear 이슈와 배포 상태를 팀 채널에서 추적하기 위한 자동화를 개발했습니다. 여러 도구를 오가며 개발 진행 상황을 확인하는 반복 작업을 줄이는 것을 목표로 했습니다.

## 담당한 개발과 검증

페이지네이션된 Slack 스레드 검색과 Linear 식별자 노출, 리뷰 댓글 묶음과 라벨 동작을 구현했습니다. 관련 스크립트·테스트·문서를 함께 작성했습니다.

워크플로 코드 병합과 검증 성공은 확인됐지만, 실제 전달 성공률이나 조직 단위 효과는 별도 자료가 없어 이 페이지에는 포함하지 않았습니다.

## AI 활용과 개발 생산성

이 프로젝트에서는 개발 도구 사이의 정보 연결과 반복 작업 자동화를 다뤘습니다. [Shotloom](/projects/shotloom/)에서는 Codex를 활용해 제작 도구를 개발하고, AI 에이전트가 작성한 결과를 직접 테스트하며 모듈의 책임과 구조를 검토했습니다.
