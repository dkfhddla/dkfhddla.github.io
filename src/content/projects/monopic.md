**기간:** 2017 ~ 2018\
**환경:** Unreal Engine 4, Spline, Instance Mesh, Node.js, AWS

사용자가 가상 공간에 갤러리를 구성하고 이미지를 공유하는 VR 플랫폼입니다.

Spline 기반 도면 편집, Instance Mesh를 이용한 벽·바닥 자동 생성과 인테리어 자산 배치를 구현했습니다. 회원가입·로그인, 서버·DB 연동과 모바일·PC Viewer도 개발했습니다.
